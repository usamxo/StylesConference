# StylesConference

A very simple, static website built using **only frontend technologies** (HTML, CSS, and JavaScript).  
No backend, databases, or build tools required — just open the `index.html` file in your browser and you're good to go.

---

## 📁 Project Structure

```text
.
├── index.html        # Main HTML file
├── styles/
│   └── style.css     # Main stylesheet
├── scripts/
│   └── main.js       # Main JavaScript file
└── assets/
    ├── images/       # Images used in the site
    └── icons/        # Icons or logos
You can rename or reorganize these folders if you like, but make sure to update the paths in index.html.

✨ Features
Pure frontend (no backend/server code)

Simple, clean layout that’s easy to customize

Responsive design (works on desktop and mobile)

Lightweight and fast to load

🛠️ Technologies Used
HTML5 – Structure and content

CSS3 – Styling and layout

JavaScript (optional) – Interactivity (e.g., menu toggle, simple animations)

No frameworks are required, but you can easily add:

Tailwind / Bootstrap for styling

React / Vue / Svelte (if you want to make it more advanced later)

2. Open in Browser
The project is static, so you have two options:

Option A: Open file directly
Double click index.html to open it in your default browser.

Option B: Use a local server (recommended)
If you have VS Code, you can use the Live Server extension:

Install the “Live Server” extension.

Right-click index.html.

Click “Open with Live Server”.
